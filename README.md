## 📌 Sobre o Projeto

Este projeto foi desenvolvido no âmbito de uma **Eletiva Escolar**, sendo um dos meus primeiros contatos práticos com o desenvolvimento web e lógica de programação. 

Inspirado na plataforma do AluraFlix, o site permite catalogar e exibir uma lista de trailers/filmes favoritos adicionados dinamicamente via interface.

---

## 🎯 Importância & Aprendizados

Este projeto representou um importante passo no início da minha trajetória em Tecnologia:

- **Lógica e Manipulação do DOM:** Primeiras interações em JavaScript para capturar entradas de dados e renderizar elementos dinamicamente na tela.
- **Integração de Mídia:** Inclusão e manipulação de links e imagens de capa de filmes.
- **Trabalho Orientado a Projetos:** Aplicação prática de conceitos aprendidos no ambiente escolar/acadêmico.
- **Evolução Contínua:** Registro do processo de transição do aprendizado básico para projetos mais complexos em TI.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura e marcação da página.
- **CSS3:** Estilização de layout e catálogo visual.
- **JavaScript (Vanilla):** Lógica para inserção e exibição dinâmica dos conteúdos.
